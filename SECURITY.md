# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.4.x   | :white_check_mark: |
| < 1.4.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Laravel Atomic Cache**, please report it responsibly by sending an email to Kazi Omar Faruk at [softeng.kaziomar@gmail.com](mailto:softeng.kaziomar@gmail.com).

Please include the following details in your report:
- Package version affected
- A short description and steps to reproduce (or proof of concept)
- Potential security impact

All security vulnerabilities will be promptly investigated and addressed. Please **do not disclose security vulnerabilities publicly** in GitHub Issues or pull requests until a fix has been prepared and released.

Thank you for helping keep Laravel Atomic Cache secure!
